## 0. 요약

1. **SAR 수면적은 2026년 저수량 감소를 크게 과소평가한다.** 8개 저수지의 SAR 쌍
   촬영 시각에 맞춰 WAMIS 공식 저수량을 받아 보니, 영천호는 면적 −9.7%인데 저수량은
   **−54.9%**(저수율 72.9→32.9%)였다. 형상지수를 어떻게 잡아도(k 1.3~2.0) 저수량에서
   기대되는 면적 감소 범위에 SAR이 들어가는 곳은 **안동호 하나**다(§2-1).
   → AREA_VS_VOLUME §5-3 의 "부호와 순위는 보존된다"는 **부호만 맞고 순위는 흔들린다.**
2. **2025년은 '평년'이 아니었다.** WAMIS 월자료 10년(2017~2026)에서 2025년 8월은
   8곳 중 6곳이 중앙값 위였고, **안동호만 10년 중 두 번째로 낮았다.** 2026년 8월은
   7곳이 10년 최저 또는 2위다(§2-2). 전년 대비 수치만으로는 가뭄 정도가 댐마다
   다른 방향으로 왜곡된다.
3. **POEORB 재처리를 시작했다.** 보고서 §5는 "정밀궤도 적용"이라고 적었지만 2026년
   산출은 사실상 전량 RESORB였다. **2026-07/08 중 남한+한강 유역 52장**을 E 드라이브로 처리 중이다(§1). 이어서 2025 잔여 37장도 같은 규격으로 큐에 있다(§1-3).
   수치 영향은 작을 것으로 보지만(궤도 오차 수 cm 대 10 m 격자) **방법 문구와 실제가
   어긋난 상태**라 고쳐야 한다.
4. **SWOT은 쓸 수 있다 — 단, 수위만.** 2026-08-01~21 한 주기에 담수호 21곳이 전부
   1~3회 관측됐고, 품질 필터를 통과한 관측의 **수위 변화량은 WAMIS와 0.01~0.2 m로
   맞았다.** 면적(`area_total`)은 소규모 호수에서 못 쓴다. 옥정호는 수위가 낮아질수록
   SWOT이 2~3 m 높게 읽는 예외다(§3).
5. **WAMIS는 이미 '정답지'다.** 계측 댐은 SAR이 아니라 WAMIS 저수율을 본문으로
   쓰고, SAR·SWOT은 **계측이 없는 곳**(농어촌공사 저수지·북한)과 **공간 분포**로 역할을
   옮기는 것이 맞다(§4·§5).

## 2. 리뷰 — 발견 사항 (심각한 순)

### 2-1. 🔴 SAR 면적이 저수량 감소를 따라가지 못한다

보고서 표 1·2 의 **같은 1:1 쌍, 같은 촬영 시각**(상승 KST 18시대, DESC 134 는 KST 익일

"면적 Δ 범위"는 `ΔA = (1+ΔV)^(1/k) − 1` 에 k = 2.0(V자)·1.3(평평)을 넣은 것이다
(HV_CURVE 실측 k 는 1.3~1.7, 일부 V자 2.0). **어느 형상을 가정해도 7곳은 SAR 이
기대 범위보다 덜 줄었다.** 7월 쌍도 같은 양상이다(임하 −2.5% ↔ 저수량 −35.9%,
영천 −8.0% ↔ −54.2%).

#### 무엇이 깨지나

- [AREA_VS_VOLUME_KR.md](AREA_VS_VOLUME_KR.md) §5-3 "같은 저수지의 전년 대비는 **부호와
  순위가 보존**된다" — **부호는 8/8 맞다. 순위는 아니다.** SAR 은 운문(4위)·영천(6위)·
  평림(8위)을 가볍게 보고, 안동(5위)을 무겁게 본다. WAMIS 저수량 순위와의 Spearman
  상관은 **0.76** 이다.
- 같은 문서 §3 "면적 −30.5% → 저수량 −30~−52%" 의 환산 폭 자체가 **너무 좁다.**
  옥정호의 실제 저수량은 −65.8%다. 면적이 덜 줄어 보이는 편향이 형상 효과 위에
  얹혀 있다.
- 보고서의 결론 중 "임하·평림은 −3% 안팎으로 작다"는 **저수량으로는 틀린 문장**이다
  (각각 −30.5%, −34.3%).

#### 왜 그런가 — 가설 (미검증)

1. **드러난 호안(사면·퇴적 갯벌)이 물로 잡힌다.** 수위가 6~21 m 내려가면 젖은
   점토·퇴적면이 넓게 드러나는데, 매끈한 젖은 면은 VH 에서 물만큼 어둡다.
   수위 하강폭이 큰 밀양(−21 m)·운문·영천에서 차이가 큰 것과 맞는다.
2. **고정 호소 폴리곤 안에서만 센다.** 2025년(만수에 가까움) 쪽 물이 폴리곤 밖까지
   차 있었다면 2025 면적이 잘려 감소폭이 줄어든다. 폴리곤 경계 화소의 수체 비율로
   바로 확인할 수 있다.
3. **급경사 협곡의 layover/shadow** — 좁은 상류 지류가 양쪽 해에 모두 무효면 변화가
   안 보인다.

**확인 방법** — 8월에 광학이 맑은 영천·성덕·운문·밀양(공통 청명 85%↑,
2026_drought_map/README §5)에서 **SAR 이 물이라고 한 호안 화소를 S2 RGB·MNDWI 로
본다.** S1–S2 결합 분석의 첫 과제로 가장 값어치가 크다. 이 결과가 나오기 전까지
SAR 저수지 면적 변화는 **"최소 이만큼은 줄었다"는 하한**으로만 인용한다.

## 3. SWOT — 실제로 받아 대조했다

### 3-1. 자료

| 항목 | 값 |
| --- | --- |
| 제품 | `SWOT_L2_HR_LakeSP_prior_D` (Version D, PO.DAAC) |
| 범위 | cycle 054, 2026-08-01 ~ 08-21 (21일 = 1주기) |
| 양 | 그래뉼 20개, 177 MB (아시아 대륙 단위 패스 파일) |
| 인증 | Earthdata 로그인 (`~/.netrc` 에 이미 있음) |
| 위치 | `downloads/swot/lakesp_prior_20260801/` |
| 레코드 | PLD(Prior Lake Database) 호수별 `wse`·`area_total`·`quality_f`·`partial_f`·`dark_frac`·저류변화 `ds1_l` 등 |

> CMR 그래뉼 footprint 는 대륙 단위라 **점 질의로 커버리지를 셀 수 없다** — 모든 날이
> 걸린다. 그래뉼을 받아 호수 레코드를 세야 한다.

### 3-2. 관측 빈도 — 21곳 전부, 주기당 1~3회

담수호 21곳 **전부** PLD 에 들어 있고 한 주기 안에 1~3회 관측됐다. 남한 위 패스는
KST 약 **00:48 · 02:26 · 11:36 · 13:14** 네 시간대다(SAR 은 06:3x·18:2x). 즉 SAR 촬영일과 **같은 날을 맞추기는
어렵고**, 같은 날 비교에는 WAMIS 시계열로 보간하는 수밖에 없다.

### 3-3. 정확도 — 수위 변화량은 좋다

같은 주기 안에서 두 번 관측된 호수의 **수위 변화량**을 WAMIS 와 비교했다.

| 저수지 | 구간 (KST) | SWOT Δh (m) | WAMIS Δh (m) | 차이 | 비고 |
| --- | --- | ---: | ---: | ---: | --- |
| 대청호 | 08-03 → 08-14 | −0.612 | −0.619 | +0.007 | partial 이지만 맞음 |
| 평림호 | 08-04 → 08-14 | −0.278 | −0.270 | −0.008 | **0.6 km² 소형 호수** |
| 합천호 | 08-03 → 08-14 | −1.351 | −1.416 | +0.065 | |
| 담양호 | 08-03 → 08-14 | −1.140 | −1.057 | −0.083 | |
| 동복호 | 08-03 → 08-14 | −0.858 | −0.666 | −0.192 | dark_frac 0.64 |
| **옥정호** | 08-03 → 08-14 | −2.033 | −2.964 | **+0.931** | ❌ §3-4 |

**절대 수위**는 `quality_f ≤ 1 & partial_f = 0` 24건에서 SWOT − WAMIS 의 |중앙값|이
0.44 m 이고, 호수마다 **거의 일정한 상수**다(안동 +0.09 · 영천 +0.05 · 임하 +0.17 ·
충주 +0.31 · 평림 +0.51 · 담양 +1.18~+1.41 · 장성 −0.42~−0.59). SWOT 은 EGM2008
지오이드 기준, WAMIS 는 국내 표고 기준이고 수위계 영점도 댐마다 달라 **호수별
상수 보정**으로 처리할 성질이다.

### 3-4. 못 쓰는 경우

| 사례 | 증상 | 해석 |
| --- | --- | --- |
| **옥정호** | SWOT 이 +2.3 m(08-03) → +3.2 m(08-14) 높게, 수위가 낮을수록 더 벌어짐 | 가설: 수위가 내려가 **상류 꼬리가 하천화**하면서 기울어진 수면이 호수 평균에 섞인다. 가뭄일수록 나빠지는 편향이라 **이 프로젝트에 가장 불리한 유형** |
| 용담호 | wse 211.6 m ↔ 실제 250.2 m, area 0.26 / 19.9 km² | partial — 호수의 아주 작은 조각만 잡혔다 |
| 소양호 | partial, 두 관측이 −0.23 / +0.63 m | partial 관측은 버린다 |
| **면적** | 평림 0.13~0.32 km²(기준 0.61), 의암 6.1(기준 10.3), 성덕 PLD 기준면적 0.054 km²(실제 약 1 km²) | **SWOT `area_total` 은 소규모 호수에서 쓰지 않는다.** 면적은 S1 이 맡는다 |

필터 규칙: **`quality_f ≤ 1` · `partial_f == 0` · `wse_u < 0.1 m`**, 그리고 호수별로
WAMIS 대비 오프셋이 일정한지 먼저 본다(옥정호 같은 경우를 걸러냄).

### 3-5. 이 프로젝트에서 SWOT 의 자리

| 상황 | 판단 |
| --- | --- |
| **WAMIS 가 있는 댐**(8개 대상 전부) | SWOT 은 **불필요**하다. WAMIS 가 매시간·cm 단위로 준다. 검증용으로만 |
| **WAMIS 가 없는 저수지** — 농어촌공사 소규모 저수지(PLD 는 1 ha 이상 수록) | **SWOT 이 유일한 수위원**이다. 평림호(0.6 km²)에서 변화량 오차 1 cm 가 근거 |
| **북한** — 황강댐 등 | WAMIS 범위 밖. SWOT 이 [FLOOD_NORTH_KOREA_KR.md](../flood/FLOOD_NORTH_KOREA_KR.md) 쪽에 주는 값이 가장 크다 |
| **다년 기준선** | SWOT 과학궤도가 2023-07 부터라 **2023~2026 네 해 여름**이 있다. S1 rel 134 처럼 연도가 비는 곳의 보완 |
| **4대강 하천 수위** | `RiverSP`(SWORD reach) — 이번에 보지 않았다 |

**SWOT 수위 + S1 면적 → `A(h)` 곡선 → `ΔV = ∫A dh`** 로 H–V 곡선 없는 저수지의
저수량 변화를 낸다는 구상은 성립한다. **다만 §2-1 이 풀리기 전에는 S1 면적 쪽이
약한 고리**라, 지금 만들면 과소평가를 그대로 물려받는다.

추가 제약: Ka 대역이라 **장마철 강우 감쇠**로 품질 플래그가 늘 수 있다(7월 자료로 확인
필요). LakeSP Version D 는 Hydrocron 시계열 API 지원 여부가 불분명해 지금은 그래뉼을
받아 읽는 방식이다.

재현:

```bash
conda run -n s1_snappy python -m s1.tools.swot.swot_fetch 2026-08-01 2026-08-21
F:\envs\gis_clean\python.exe -m s1.tools.swot.swot_vs_wamis downloads/swot/lakesp_prior_20260801
```

## 5. 권장 순서

1. **보고서 프레이밍을 바꾼다.** 8개 대상은 전부 WAMIS 계측 댐이다. 본문 수치는
   **WAMIS 저수율·10년 순위**(§2-1·2-2)로 하고, SAR 은 "같은 기간 수면 분포가 어떻게
   변했나"와 **계측 없는 유역·저수지**로 역할을 옮긴다. 학회 포스터·KJRS 원고에서 특히
   중요하다 — 심사에서 공식 저수율과 대조당하면 §2-1 의 차이가 바로 드러난다.
2. **POEORB 재처리 완료 → VRT·표 재산출**(§1-4).
3. **§2-1 원인 진단** — 8월 청명 4개 유역에서 S1 수체 ↔ S2 RGB/MNDWI 호안 대조.
   S1·S2 결합의 본론이 된다.
4. **강우 위상 태그** — WAMIS `dambsarf` 로 관측일 직전 5일 강우를 붙인다.
5. **WAMIS 목록 축소 대응**(§2-4) — 작은 수정.
6. **SWOT 확장은 그 다음.** 7월 cycle(장마 영향) 확인 → 2023~2026 여름 시계열 →
   농어촌공사 저수지·북한 시범.
